# Changelog

## [0.1.0] - 2026-10-08

First public release.

- Dynamic color: material-color-utilities port (all variants, contrast levels, spec 2021 / 2025).
- Compose Material 3 tokens, type and shape scales; MaterialShapes and shape morphing (SDF shader).
- Expressive / standard motion schemes (spring motion).
- Components: buttons, icon buttons, FABs, FAB menu, button groups, split and segmented buttons, checkbox, radio, switch, sliders, progress and loading indicators, chips, badges, cards, dividers, lists, text fields, docked and full-screen search, menus, dialogs, snackbars, tooltips, bottom sheet, navigation bar, wide and modal navigation rail, navigation drawer, tabs, top app bars, toolbars, date / date range / time pickers, scroll field, carousel.
- VRChat (UdonSharp) and plain Unity from the same source; showcase app.
