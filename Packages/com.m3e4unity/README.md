# M3E4Unity (com.m3e4unity)

Material 3 Expressive for Unity uGUI: dynamic color, the Compose Material 3 tokens, MaterialShapes, spring motion and builders for every Material 3 Expressive component. Works in plain Unity and in VRChat worlds (UdonSharp).

Documentation, screenshots and the showcase app: https://github.com/NarYuki/M3E4Unity
